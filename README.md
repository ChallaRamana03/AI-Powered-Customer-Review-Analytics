# AI-Powered Customer Review Analytics

## Project Overview

This project analyzes customer reviews from a women's clothing e-commerce dataset to understand customer satisfaction, product performance, and purchasing behavior.

Using Excel, SQL, Power BI, Python, and Generative AI, raw customer reviews were transformed into meaningful business insights and interactive visualizations.

---

## Tools & Technologies

* Excel
* MySQL
* Power BI
* Python (Pandas)
* Generative AI

---

## Project Workflow

1. Data Cleaning and Preparation using Excel
2. Business Analysis using SQL
3. Interactive Dashboard Development using Power BI
4. KPI Analysis using Python (Pandas)
5. AI-Powered Customer Feedback Analysis using Generative AI

---

## Business Questions Answered

* What is the overall customer satisfaction level?
* What is the customer recommendation rate?
* Which departments receive the highest number of reviews?
* Which product categories are most popular?
* Which customer age groups contribute the most reviews?

---

## Key Insights

* Analyzed **20,603 customer reviews**.
* Achieved an average customer rating of **4.19/5**.
* Identified a recommendation rate of **82.13%**.
* Found that **Tops** and **Dresses** received the highest number of reviews.
* Identified key customer concerns related to sizing consistency and product quality.
