# AI-Powered Customer Review Analytics## Project OverviewThis project analyzes customer reviews from a women's clothing e-commerce dataset to identify customer satisfaction trends, product performance, and business insights.The project combines Excel, SQL, Power BI, Python, and Generative AI to transform raw customer feedback into actionable insights.---## Tools Used* Excel* MySQL* Power BI* Python (Pandas)* Generative AI---## Project Workflow1. Data Cleaning using Excel2. Data Analysis using SQL3. Interactive Dashboard using Power BI4. KPI Analysis using Python5. AI-Powered Customer Insight Generation---## Business Questions Answered* What is the overall customer satisfaction level?* Which department receives the most reviews?* Which department has the highest average rating?* Which product categories are most popular?* Which age groups contribute the most reviews?---## Key Insights* Analyzed 20,000+ customer reviews.* Achieved an average customer rating above 4.0.* Identified top-performing departments and product categories.* Measured customer recommendation behavior.* Generated AI-powered summaries of customer feedback.---## Dashboard Features* Total Reviews KPI* Average Rating KPI* Recommendation Rate KPI* Reviews by Department* Average Rating by Department* Top Product Categories* Reviews by Age Group* Interactive Department Filter---## Project Files* customer_reviews_cleaned.xlsx* customer_review_analysis.sql* customer_review_analysis.py* AI_Powered_Customer_Review_Analytics.pbix* genai_customer_insights.txt---## Generative AI InsightsGenerative AI was used to analyze customer reviews and identify:* Positive customer themes* Negative customer themes* Customer sentiment patterns* Business recommendations---## Project OutcomeThis project demonstrates end-to-end Data Analytics skills including data cleaning, SQL analysis, dashboard development, Python analysis, and AI-powered business insight generation.
